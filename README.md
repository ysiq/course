# PCT-100 过程控制实训课程 - 课件

## 内容说明
本仓库存放 PCT-100 过程控制实训设备配套课件（HTML 版本），包含：

| 文件 | 说明 |
|------|------|
| `index.html` | 课程主页，含两课时导航链接 |
| `第9课时.html` | 第9课时：前端开发与 GitHub Pages 部署 |
| `第10课时.html` | 第10课时：Node.js 与 Electron 桌面应用开发 |
| `images/` | 配图文件夹（共 13 张） |

## 维护说明
### 添加新图片
1. 将图片放入 `images/` 目录
2. 在对应 HTML 文件中用 `<img src="images/xxx.png">` 引用

### 修改课程内容
直接编辑对应 `第N课时.html` 文件，修改后刷新浏览器即可预览。

### 部署
本仓库已启用 GitHub Pages，push 后等待 1-2 分钟即可通过以下地址访问：
https://ysiq.github.io/course/
